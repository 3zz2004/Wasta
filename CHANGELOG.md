# Changelog

## 0.1.0

First release, for JavaScript and Python.

- `parsePhone` / `parse_phone`: Egyptian mobile numbers in any common format
- `parseNationalId` / `parse_national_id`: birth date, governorate and gender from a national ID
- `tafqeet` and `numberToArabicWords` / `number_to_arabic_words`: amounts in Arabic words
- `governorates` and `findGovernorate` / `find_governorate`: all 27 governorates with fuzzy lookup
- `normalizeArabic` / `normalize_arabic`, `toWesternDigits`, `toArabicDigits`
